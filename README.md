# Zombie-Survival-Game
Developed a 2D Zombie Survival Game using C++ and the SFML library, applying object-oriented programming principles to build a modular and interactive game. 
Key Features:

- 🎮 Player movement with keyboard controls and real-time shooting mechanics.
- 🧟 Intelligent zombie AI that tracks and follows the player.
- 🌊 Progressive wave system with increasing difficulty.
- ❤️ Health management, scoring system, and live game HUD.
- 💥 Collision detection for bullets, zombies, and player interactions.
- ⚡ Optimized gameplay with bullet cooldown and smooth game loop.
- 🏆 Modular architecture using separate classes for Player, Zombie, Bullet, BossZombie, Game, PowerUps, and resource management.

Tech Stack:

C++, SFML, Object-Oriented Programming (OOP), Game Development, Collision Detection, Event Handling, Data Structures

This project strengthened my understanding of game development concepts, object-oriented design, real-time event processing, and efficient resource management while creating an engaging desktop game experience.
